# 全局富文本步进功能

> 状态：2026-04-25 首轮全局化已完成，本文档现在记录**当前有效合同**，不再描述“仅 quiz 有富文本步进”的旧现状。

## 1. 当前能力边界

整个课件现在已经存在两套富文本能力：

1. 顶部主编辑工具栏添加的普通富文本格式。
    - 放映时直接展示；
    - 不参与隐藏 / reveal / 片段步进协议。
2. 选中文本后通过浮动工具条添加的隐藏型富文本标注。
    - 放映 / 涂鸦时默认隐藏；
    - 通过 hover、右键 reveal、`←→` 片段步进被唤醒；
    - 统一复用 authored fragment 协议：`data-fragment-step="true"`、`data-fragment-group`、`data-fragment-format`。

## 2. 普通页面隐藏型标注的作者态合同

1. 只允许在普通页面、普通 `[data-edit-id]` 根块内创建隐藏型标注；跨多个根块的选区仍视为非法。
2. 普通页专用浮动工具条是 `page-richtext-fragment-toolbar`，语义上必须与顶部主工具栏、quiz 工具条区分开。
3. 当前首版继续只复用既有五种片段格式：文字颜色、背景高光、删除线、顶标、清除格式。
4. 作者保存时，隐藏型标注继续写入 `.annotations.js` 侧车；导出 HTML 时会剥离临时 reveal 状态，只保留 authored 结构。

## 3. 放映 / 涂鸦态合同

1. 普通页面隐藏型标注默认隐藏，但底层原文保持可读。
2. 鼠标悬浮到拥有隐藏型标注的普通文本根块时，会显示橙色 hover 提示并播放 hover cue。
3. 鼠标右键点击普通文本根块时，会立即 reveal 该宿主的下一组隐藏片段。
4. 键盘 `←→` 不再按“整页所有文本根块”盲目推进，而是**严格挂在当前一级焦点宿主之下**：
    - 先通过 `↑↓` 或鼠标左键把一级焦点落到某个组件根；
    - 再由 `←→` 推进这个宿主内部的隐藏型片段。

## 4. 与一级步进系统的协同

1. 普通展示组件和互动组件现在都会进入一级焦点队列：`card`、`stat-card`、`timeline-card`、`code-window`、`chart-container`、`table-wrap`、`image-block`、`dual-bar`、`content-block`、`flip-card`、`collapse-card`、`summary-trigger` 等都可以成为宿主。
2. 普通展示组件只负责承载焦点与片段，不额外产生顶层 forward 动作。
3. 普通页互动组件采用“先聚焦、后互动”的两步模型：
    - `ArrowDown` 第一次只把焦点落到宿主；
    - 再次 `ArrowDown` 才执行 flip / expand / summary 打开；
    - `ArrowUp` 先撤销互动，再下一次才离开该宿主。
4. `summary-panel` 内 authored 的普通页面片段由 `summary-trigger` 按钮本体持有宿主资格，不会把 panel 里的 `li[data-edit-id]` 误塞成新的一级焦点项。

## 5. 特殊组件与排除规则

1. `quiz-annotation` 组件继续保持原有的编辑方式、显示方式、步进方式和提交流程；本轮普通页 redesign 不改写 quiz 内部合同。
2. 页面中只要存在 `quiz-annotation`，普通页面隐藏型标注运行时就在放映 / 涂鸦态整页禁用，避免 hover、右键 reveal、`←→` 与 quiz 内部规则冲突。
3. 未来例题组件如果复用隐藏型标注，也应沿用“提交答案前静默、提交后激活”的 quiz 级门禁逻辑。
